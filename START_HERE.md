## 🚀 Quick Start (5 Minutes)

### Terminal 1: Backend
```bash
cd backend
npm install
cp .env.example .env
npm run migrate
npm run dev
```

### Terminal 2: Frontend
```bash
cd frontend
npm install
cp .env.example .env.local
npm start
```

### Visit: `http://localhost:3000`

**That's it!** The entire marketplace is running locally.
